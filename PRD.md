# Tim's Anthropic API Test Bed

A teaching-focused sandbox for the **Anthropic Messages API** using Python only.

## Scope

- Basic request/response flow
- Streaming responses
- System prompt patterns

## Stack

- Python 3.11+
- Anthropic Python SDK
- uv for dependency management
- ruff for linting
- pytest for smoke tests

## Non-goals

- Tool use / function calling (future)
- Vision / image input (future)
- Production deployment patterns
